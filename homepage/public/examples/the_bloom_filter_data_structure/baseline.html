The Bloom Filter

A Space-Efficient Probabilistic Data Structure

1. What is a Bloom Filter?

A Bloom filter is a probabilistic data structure designed to tell you, rapidly and memory-efficiently, whether an element is present in a set.

It is unique because it never results in false negatives (if the filter says an element isn't there, it's definitely not there), but it can result in false positives (if the filter says it's there, it might be there).

  • Add(x): Inserts an element into the set.
  • Check(x): Returns "Probably in set" or "Definitely not in set".

2. How It Works

A Bloom filter consists of two components:

  1. A bit array of size m, initialized to all 0s.
  2. A set of k independent hash functions, each mapping an input to one of the m array positions.

To add an item, you run it through all k hash functions and set the bits at those positions to 1. To check an item, you run it through the same hash functions. If all bits at those positions are 1, the item is probably in the set. If any bit is 0, the item is definitely not in the set.

4. Use Cases & Trade-offs

Bloom filters are used when memory is at a premium and a small error rate is acceptable:

  • Database Caching: Preventing expensive disk lookups for keys that don't exist.
  • Spam Filtering: Checking if an email address is in a list of millions of known spammers.
  • Web Browsers: Checking if a URL is a known malicious site before loading it.

Note: You cannot remove an item from a standard Bloom filter. If you flip a bit back to 0, you might inadvertently "delete" other items that shared that bit!
