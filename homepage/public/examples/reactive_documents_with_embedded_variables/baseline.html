Reactive Documents

Explore the power of documents where the narrative changes as the data does.

1. What is Reactivity?

A reactive document is one where the text and elements update automatically when the underlying data changes. Instead of static text, we use embedded variables that act as placeholders for dynamic values.

Try changing your name below to see how it propagates through the sentence:

Hello, Explorer! By typing in that box, you are updating a variable that is bound to this paragraph.

2. Dynamic Logic & Narrative

Reactive documents allow the "story" to change based on thresholds. We can use conditional logic to swap out entire phrases or sentences based on slider values.

Today the weather is mild. You should probably wear a light sweater.

3. Mathematical Dependency

Reactivity is most powerful when variables depend on other variables. In this example, Total Cost is a calculated variable based on Quantity and Price.

Total = 5 * 10 = $50

If you increase the order to more than 50 units, a 10% discount is applied automatically.

Final Bill: No discount applied. Amount Due: $50.00.

4. Why use Reactive Documents?

  • Explainable Models: Users can "play" with variables to see how outcomes change.
  • Personalization: Content adapts to the specific user's inputs.
  • Reduced Friction: No need to recalculate or rewrite sections after a data tweak.
