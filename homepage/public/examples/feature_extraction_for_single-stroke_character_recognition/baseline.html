Feature Extraction for Characters

Mastering the fundamentals of Single-Stroke Recognition

1. The Challenge of Raw Data

In single-stroke recognition (like the old Palm OS Graffit), a computer doesn't see a "letter." It sees a sequence of 2D coordinates: [(x₁, y₁), (x₂, y₂), ... (xₙ, yₙ)].

Raw points are problematic because they vary by scale (writing big vs small), translation (writing in a corner vs center), and sampling rate (fast vs slow movement). Feature Extraction transforms this messy raw data into a compact set of values that represent the essence of the shape.

3. Global vs. Local Features

We typically look for two types of features:

  • Global Features: Aspect ratio, Total length, Cosine of total angle.
  • Local Features: Directional change between points, Curvature, and Relative position to the center.

4. Mapping to Meaning

Once we have a Feature Vector (e.g., [1.2, 45.5, 0.8]), we compare it to a template database or feed it into a machine learning classifier. For single-stroke gestures, the most powerful feature is often the Resampled Direction Vector—breaking the stroke into a fixed number of segments (e.g., 16) and calculating the angle of each segment.
