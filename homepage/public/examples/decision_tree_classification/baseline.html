1. What is a Decision Tree?

A Decision Tree is a supervised learning algorithm used for classification. It works like a flowchart where each internal node represents a "test" on an attribute, each branch represents the outcome of the test, and each leaf node represents a class label.

Analogy: Imagine deciding whether to play tennis based on the weather. If it's raining, you don't play. If it's sunny, you check the humidity. This hierarchical decision-making is exactly how the algorithm operates.

2. Choosing the Best Split

Decision Trees use specific metrics to decide how to split the data. The goal is to maximize Information Gain (finding the split that makes the resulting groups as "pure" as possible).

Gini Impurity Formula:
G = 1 - Σ (pi)²
Where pi is the probability of an item belonging to a specific class. Lower is better!
  • Entropy: Measures randomness. High entropy means mixed labels; zero entropy means all items belong to one class.
  • Pruning: The process of removing branches that provide little power to classify instances, helping prevent Overfitting.

4. Strengths & Weaknesses

Advantages

  • Easy to understand and visualize (White Box).
  • Requires little data preparation (no scaling needed).
  • Handles both numerical and categorical data.

Disadvantages

  • Prone to overfitting (creating over-complex trees).
  • Unstable: small changes in data can result in a completely different tree.
  • Biased towards features with many levels.
