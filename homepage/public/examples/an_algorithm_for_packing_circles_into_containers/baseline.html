Circle Packing Algorithms

Exploring the geometry and logic of filling spaces with non-overlapping circles.

1. The Challenge

Circle packing is the study of how to arrange circles on a given surface such that no two circles overlap. This is a classic problem in computational geometry and has practical applications in:

  • Material Science: Arranging fibers or particles.
  • Logistics: Efficiently loading cylindrical goods into containers.
  • Data Visualization: Representing hierarchical data (Circle Treemaps).

3. How the Algorithm Works

The logic used in the simulation above follows these steps:

  1. Selection: Pick a random point (x, y) within the canvas.
  2. Validation: Check if (x, y) is inside any existing circle. If it is, discard this attempt.
  3. Creation: If the point is valid, create a new circle with radius r = 1.
  4. Expansion: In every frame of the animation:
    • Increment the radius of all "active" circles.
    • Check if the circle has hit the canvas edge.
    • Check if the circle has hit any other circle using the distance formula:
      dist = sqrt((x2-x1)² + (y2-y1)²).
    • If a collision is detected, stop the growth of that circle.

4. Optimization Strategies

As the number of circles increases, checking every circle against every other circle becomes computationally expensive (O(n²)). Experts use these techniques to optimize:

  • Spatial Partitioning: Diving the container into a grid. Only check collisions with circles in the same or adjacent grid cells.
  • Apollonian Gasket: A mathematical fractal approach that fills the gaps between larger circles with smaller ones.
  • Force-Directed Layouts: Using physics (repulsion) to push circles apart until they settle into an equilibrium.
