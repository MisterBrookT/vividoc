Probabilistic state transitions in Markov chains

A Markov chain is a stochastic model that describes a sequence of possible events in which the probability of each event depends only on the state attained in the previous event. This core principle is known as the Markov Property, often summarized as "memorylessness." Formally, if we have a sequence of random variables $X_0, X_1, X_2, \dots$, the probability of the future state $X_{n+1}$ is determined entirely by the current state $X_n$, regardless of the path taken through $X_0, \dots, X_{n-1}$.

To mathematically model these transitions, we define a state space, which is a set of all possible conditions the system can occupy. For a system with $n$ discrete states, we represent the movement between these states using a transition matrix $P$. This square matrix serves as an organized map of probabilities, where each element $P_{ij}$ represents the probability of transitioning from state $i$ to state $j$ in a single time step:

$$P_{ij} = P(X_{n+1} = j \mid X_n = i)$$

In a transition matrix, each row corresponds to the "current state" and each column to the "next state." Because the system must always transition to some state (even if it transitions back to itself), the sum of the probabilities in any given row must always equal 1:

$$\sum_{j=1}^{n} P_{ij} = 1$$

These matrices are known as stochastic matrices. By looking at a transition matrix, we can instantly see the dynamics of the system: a value of $P_{ij} = 0$ indicates an impossible transition, while $P_{ij} = 1$ indicates a certain transition. Through this framework, we can transform complex behavioral observations into a rigorous linear algebra structure.

While the transition matrix $P$ defines the theoretical rules of a system, a random walk brings these rules to life by simulating a single realization of the process. To begin a simulation, we define an initial state $X_0$. At each discrete time step $n$, the system "queries" the transition matrix: it looks at the row corresponding to the current state $X_n$ and treats the probabilities in that row as a categorical distribution to determine the next state $X_{n+1}$.

Mathematically, this process is akin to sampling from a distribution. If the system is currently in state $i$, the next state $j$ is chosen such that the likelihood of picking $j$ is exactly $P_{ij}$. As we repeat this for $N$ steps, we generate a sample path or trajectory: a specific sequence of states $(x_0, x_1, x_2, \dots, x_N)$ that represents one possible "history" of the system. Because Markov chains are stochastic, two simulations starting from the same $X_0$ and using the same matrix $P$ will likely produce entirely different paths.

Visualizing these paths is crucial for understanding system dynamics. By observing a single path, we can identify patterns that might be obscured by the raw numbers in a matrix. For instance, in a two-state system, a path might reveal that the system tends to "get stuck" in a specific state for long periods (high self-transition probability) or that it oscillates rapidly between states. Over many steps, the relative frequency with which the path visits each state begins to approximate the underlying long-term behavior of the Markov chain.

As we extend a random walk over thousands of iterations, a remarkable pattern emerges: the local fluctuations of the sample path give way to a global stability. While we cannot predict the exact state of the system at step $n=1,000,000$, we can often predict the probability of being in any specific state with near-certainty. This long-term behavior is captured by the steady-state distribution (also called the stationary distribution), represented by the row vector $\pi$.

A distribution $\pi$ is considered stationary if, after applying the transition matrix $P$, the distribution remains unchanged. Formally, this is expressed by the matrix equation:

$$\pi P = \pi$$

In this equation, $\pi$ is a probability vector where all elements sum to 1 ($\sum \pi_i = 1$). From a linear algebra perspective, the stationary distribution is a left eigenvector of the transition matrix $P$ associated with the eigenvalue $\lambda = 1$. If a Markov chain is irreducible (you can get from any state to any other state) and aperiodic (it doesn't get trapped in a repeating cycle), the system will eventually converge to this unique distribution regardless of the initial starting state $X_0$.

This convergence has profound implications for modeling. It tells us that the "memory" of the starting conditions eventually fades away, and the system settles into a statistical equilibrium. For a two-state system, if we let $\pi = [ \pi_A, \pi_B ]$, we can solve for the steady state by observing that the flow out of State A must equal the flow into State A:

$$\pi_A P_{AB} = \pi_B P_{BA}$$

This balance equation allows us to calculate exactly what fraction of time the system will spend in each state over an infinite horizon. Whether modeling weather patterns, stock market regimes, or web page rankings (like Google's PageRank), finding the steady state reveals the intrinsic importance or long-term occupancy of each node in the network.
