Markov Chains

Navigating the World of Probabilistic State Transitions

1. What is a Markov Chain?

A Markov Chain is a stochastic model describing a sequence of possible events in which the probability of each event depends only on the state attained in the previous event.

This is often called the Markov Property: The future is independent of the past, given the present. In other words, you don't need to know the history of how you got to "State A" to predict where you will go next; you only need to know that you are currently in "State A".

2. Transition Probabilities

Transitions are the movements between states. Each transition has an associated probability. If we have two states, Sunny (S) and Rainy (R), we can define a Transition Matrix:

P = [ P(S|S) P(R|S) ]
    [ P(S|R) P(R|R) ]

Key rule: The sum of probabilities for all outgoing edges from any single state must always equal 1.0 (100%).

4. Calculating the Future

If the current state vector is v, the state after one step is vP. To find the state after n steps, you calculate vPn.

Over a long period, many Markov chains reach a Stationary Distribution, where the probability of being in any given state remains constant even as the system continues to transition.
