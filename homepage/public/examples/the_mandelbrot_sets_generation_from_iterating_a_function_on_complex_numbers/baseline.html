The Mandelbrot Set

A journey from a simple equation to infinite complexity.

1. The Iterative Seed

The Mandelbrot set is defined by a surprisingly simple rule applied to complex numbers. We take a starting point c on the complex plane and repeatedly apply the following function:

zn+1 = zn2 + c

We always start with z0 = 0. The "set" consists of all points c for which this sequence does not escape to infinity, no matter how many times we iterate.

2. Boundaries of Chaos

How do we know if a number "escapes"? If the absolute value (the distance from zero) of z ever exceeds 2, it is proven that the orbit will eventually head to infinity.

Points that stay "trapped" forever are colored black. Points that escape are colored based on how fast they escaped—this creates the beautiful gradients and psychedelic patterns we associate with fractals.

Key Concepts:
  • Orbit: The path of points z0, z1, z2...
  • Divergence: When a point flies off to infinity.
  • Self-Similarity: Zooming in reveals smaller versions of the whole.

4. Why It Matters

Discovered by Benoit Mandelbrot in 1980, this set became the faces of Fractal Geometry. It demonstrates how deterministic, simple rules can generate "organized chaos." It has applications in computer graphics, fluid dynamics, and even understanding the structure of the universe.
