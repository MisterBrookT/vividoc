Principal Components Analysis for Dimensionality Reduction

At its core, Principal Components Analysis (PCA) operates on a fundamental assumption: variance is a proxy for information. In the context of data, "information" refers to the patterns, structures, and differences that allow us to distinguish between individual data points. If a feature has zero variance, every single observation is identical, and that feature tells us nothing about the underlying diversity of the dataset.

Imagine a 2D scatter plot representing two highly correlated features, such as height and weight. If we plot these points, we see an elongated "cloud." While we have two variables ($x$ and $y$), the data primarily stretches along a single diagonal path. Most of the "spread" or variance in this dataset is not strictly horizontal or strictly vertical; it is oriented in the direction where the points are most dispersed.

In PCA, we seek the Principal Components, which are new axes that better represent this dispersion. The first principal component is essentially a "best-fit" line that passes through the multidimensional mean of the data. However, unlike standard linear regression which minimizes the vertical distance to the line, PCA finds a line that maximizes the variance of the projected points. Mathematically, for a set of points $X$, we look for a direction vector $w$ such that the variance of the projected data $Xw$ is maximized:

$\max_{w: \|w\|=1} \{ \text{Var}(Xw) \}$

By finding this direction, we capture the maximum amount of "signal" from the data while treating smaller, perpendicular variations as less significant "noise." This shift in perspective—from viewing data as a collection of fixed features to viewing it as a continuous field of variance—is the critical first step in reducing dimensions without losing the essence of the original information.

To mathematically define these optimal axes, we transition from the raw data points to a summary of their relationships: the Covariance Matrix. If our data is centered (mean subtracted), the covariance matrix $\Sigma$ captures how every pair of variables changes together. The pursuit of the "direction of maximum variance" is equivalent to solving an eigenstructure problem for this matrix. Specifically, we seek the vectors $v$ that satisfy the equation:

$\Sigma v = \lambda v$

In this expression, $v$ represents an eigenvector—a direction that remains unchanged in orientation when the linear transformation $\Sigma$ is applied. The scalar $\lambda$ is the corresponding eigenvalue, which quantifies the amount of variance spread along that specific eigenvector. When we sort these eigenvalues from largest to smallest, the eigenvector associated with the largest eigenvalue becomes our First Principal Component (PC1).

A defining constraint of PCA is that each subsequent component must be orthogonal (perpendicular) to the ones before it. This ensures that each principal component captures a unique, non-redundant portion of the data's total variance. If PC1 follows the longest "stretch" of a data cloud, the Second Principal Component (PC2) will align with the next widest direction that is exactly $90^\circ$ to PC1. In a 2D space, once PC1 is fixed, PC2 is automatically determined.

The total "information" in the dataset is the sum of all eigenvalues. By calculating the ratio $\frac{\lambda_i}{\sum \lambda}$, we determine the Proportion of Variance Explained by the $i^{th}$ component. This allows us to make an informed decision: if the first two components capture 95% of the total variance, we can discard all other dimensions while retaining nearly all the critical structure of the original data.

Once we have identified the principal components and their relative importance, we arrive at the definitive step of PCA: dimensionality reduction. This is achieved by projecting the high-dimensional data points onto a lower-dimensional subspace formed by the top $k$ eigenvectors. In a 2D-to-1D reduction, this means we "collapse" every data point onto the line defined by the first principal component (PC1), effectively discarding the information contained along the PC2 axis.

Mathematically, if $W_k$ is a matrix containing the first $k$ eigenvectors as columns, the reduced representation $Z$ of our data $X$ is calculated as $Z = XW_k$. This transformation redefines each observation not by its original $x$ and $y$ coordinates, but by its score—its position along the new PC1 axis. While we have halved the number of variables, the "distance" between points along this axis captures the maximum possible differentiation present in the original dataset.

This process inevitably incurs a reconstruction error, often referred to as the "residual variance." Because we ignore the components with smaller eigenvalues, we lose the fine-grained fluctuations that occurred perpendicular to our chosen subspace. However, in many real-world datasets, these smaller components represent stochastic noise or measurement error rather than meaningful signal. By deliberately "dropping" these dimensions, we produce a simplified, compressed version of the data that is easier to visualize, less computationally expensive to process, and often more robust for machine learning tasks.

The trade-off of PCA is thus a balance between compression and fidelity. We aim to choose a value for $k$ such that we minimize the number of dimensions while maximizing the cumulative explained variance: $\sum_{i=1}^{k} \lambda_i / \sum_{j=1}^{d} \lambda_j \approx 1$ By retaining enough components to explain 90% or 95% of the total variance, we ensure that the "shadow" cast by our data onto the lower-dimensional surface still retains the essential shape of the original high-dimensional object.
