Principal Component Analysis (PCA)

Mastering Dimensionality Reduction through Variance Maximization

1. What is PCA?

Principal Component Analysis (PCA) is a statistical technique used to simplify complex datasets. In the real world, data often has many variables (dimensions). PCA helps us reduce these dimensions while retaining as much information (variance) as possible.

Key concepts:

  • Dimensionality Reduction: Transforming data from a high-dimensional space to a lower-dimensional space.
  • Principal Components: New, uncorrelated variables constructed as linear combinations of the original variables.
  • Eigenvectors: Determine the direction of the new axes.
  • Eigenvalues: Determine the magnitude (importance) of each axis.

3. The Step-by-Step Algorithm

  1. Standardization: Scale the data so each feature has a mean of 0 and a standard deviation of 1. PCA is sensitive to variances of original variables.
  2. Covariance Matrix: Compute the matrix to identify correlations between variables.
    Σ = 1/(n-1) * (X^T X)
  3. Eigendecomposition: Calculate eigenvectors and eigenvalues from the covariance matrix.
  4. Sort & Select: Sort eigenvalues in descending order. Choose the top k eigenvectors to form a projection matrix.
  5. Project: Transform the original data into the new k-dimensional subspace.

4. Why use PCA?

  • Visualization: Reducing 100+ variables to 2D or 3D to identify clusters.
  • Noise Filtering: By dropping components with low eigenvalues, we often remove "noise" from the data.
  • Feature Extraction: Creating a smaller set of features for machine learning models to prevent overfitting and speed up training.
