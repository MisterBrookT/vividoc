拖动 w₁、w₂ 改变决策直线的斜率；调节 b 平移它。尝试让准确率达到 100%——看看什么情况下不可能做到。

感知机的本质是在特征空间里画一条直线：调整 w₁ 和 w₂ 决定直线的方向，调整 b 决定它的位置。对于线性可分的数据集，你总能找到一组参数让准确率达到 100%；但面对右侧的 XOR 型数据分布，无论如何旋转或平移那条线，都至少有一类点被错误划分。

这个局限并非调参失误，而是单个神经元的结构性边界——它只能表达线性函数。要打破这一限制，需要将多个神经元层叠堆砌，让网络学会弯曲自己的"决策面"。这正是下一节要讨论的主题。

非线性激活函数是深度网络的灵魂。当你切换到"线性激活"模式时，无论隐藏层有多少个神经元，整个网络的输出依然只是输入的一个线性组合——层叠的矩阵乘法最终可以被化简为单个矩阵，深度完全失去意义。而 ReLU 将负值截断为零，正是这个看似简单的非线性操作，让每个神经元能够"选择性激活"，网络整体才具备了拟合任意复杂曲面的能力。

但仅仅有了正确的网络结构还不够——权重的初始值几乎是随机的，网络需要从错误中学习、反复调整。怎样把输出层的误差传递回每一个权重，让它们都知道"该往哪个方向调"？这就是下一节反向传播要解决的核心问题。

# 链式法则：反向传播的核心
# 损失对权重的梯度 = 三段偏导的乘积

dL_da  = output - target            # ∂L/∂a  (MSE 损失梯度)
da_dz  = sigmoid(z) * (1 - sigmoid(z))  # ∂a/∂z  (激活函数梯度)
dz_dw  = x                         # ∂z/∂w  (线性变换梯度)

dL_dw  = dL_da * da_dz * dz_dw    # 链式法则
w      = w - lr * dL_dw             # 梯度下降更新

反向传播是链式法则的计算实现，让误差信号从输出层逆向流回每一个权重。网络的每个连接都能知道自己"该向哪个方向调整、调整多少"——这正是学习的本质。学习率是控制步长的关键超参数：太大，梯度在最优点附近反复震荡，损失曲线如锯齿般抖动；太小，网络如蜗牛前行，需要数倍的迭代才能收敛。

感知机的那条直线，在反向传播的驱动下，演变为多层网络中弯曲的决策曲面——它可以是识别猫狗的图像分类器，可以是翻译语言的 Transformer，也可以是生成文字的大语言模型。从一个神经元到万亿参数，改变的是规模，不变的是梯度沿链式法则流动的本质逻辑。
