A single parameter separates order from chaos: below ρ = 1 every trajectory collapses to the origin; above ρ ≈ 24.74 the fixed points destabilize and chaos erupts. The iconic butterfly shape exists only in a narrow band of ρ values — change one number and an entirely different universe appears.
