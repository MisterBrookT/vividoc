Decision Boundaries

k-NN · Logistic Regression · SVM

Section 01

k-Nearest Neighbors

Instance-based learning takes a fundamentally different approach to classification than parametric models. Rather than fitting a global function during training, k-Nearest Neighbors simply memorizes the entire training set. At prediction time, it finds the k closest training examples—by Euclidean distance or another metric—and lets them vote. The predicted class is whatever the majority holds. This "lazy learning" strategy is surprisingly powerful, yet carries a deep cost: every prediction requires scanning all stored examples, and storing the entire dataset in memory becomes prohibitive as data grows.

The concept of a decision boundary emerges naturally from this voting process. Imagine the feature space divided into a grid of tiny cells. Each cell gets classified by querying the k nearest training points. Where the majority vote flips from one class to the other, you have the decision boundary. With k = 1, each cell is claimed entirely by its single nearest neighbor, producing the Voronoi diagram—a jagged, highly complex partition of space. As k increases, the boundary smooths: distant points influence the vote, outliers get outvoted, and the frontier becomes a gentler curve.

This tradeoff between k = 1 (maximum complexity, zero training error, maximum variance) and large k (smooth boundary, some misclassification, high bias) is one of the clearest illustrations of the bias-variance tradeoff in all of machine learning. The optimal k is typically found by cross-validation. Notably, as the training set size n → ∞, the error rate of 1-NN approaches at most twice the Bayes error—a remarkable theoretical guarantee.

Distance metrics determine which points count as "near." In high dimensions, the curse of dimensionality strikes: as dimensions grow, all points become roughly equidistant from any query point, dissolving the notion of locality. k-NN silently breaks in hundreds of dimensions unless features are carefully selected or the data lives on a low-dimensional manifold. This is why feature engineering, PCA, or learned embeddings often precede k-NN in practice.

$$\hat{y}(x) = \underset{c}{\arg\max} \sum_{x_i \in \mathcal{N}_k(x)} \mathbf{1}[y_i = c]$$

Section 02

Logistic Regression

Logistic regression reframes binary classification as probabilistic prediction. Instead of asking "which class?", it asks "what is the probability of class 1?" The model computes a linear combination of features—$w_1 x_1 + w_2 x_2 + b$—then squashes this score into the interval $(0, 1)$ via the sigmoid function $\sigma(z) = 1/(1 + e^{-z})$. Predict class 1 when this probability exceeds 0.5, and class 0 otherwise. The surface where $P = 0.5$ is exactly where the linear score equals zero: this is the decision boundary, and it is always a hyperplane.

Training finds weights that maximize the likelihood of the observed labels. Equivalently, it minimizes the cross-entropy loss: $\mathcal{L} = -\sum_i [y_i \log \hat{p}_i + (1-y_i)\log(1-\hat{p}_i)]$. This is a convex objective with a unique global minimum, which gradient descent reliably finds. The gradient update for each weight is beautifully intuitive: it is proportional to the prediction error $(y_i - \hat{p}_i)$ times the feature value, pushing the model to correct its largest mistakes most aggressively.

The weight vector $\mathbf{w} = (w_1, w_2)$ has a geometric meaning: it is perpendicular to the decision boundary. To see why, recall that the boundary is the set $\{x : \mathbf{w} \cdot x + b = 0\}$—a hyperplane whose normal is $\mathbf{w}$. The magnitude $\|\mathbf{w}\|$ controls the steepness of the sigmoid "ramp": large weights produce a sharp, near-step transition; small weights produce a gentle gradient. This means logistic regression can represent both crisp and uncertain decisions.

The fundamental limitation of logistic regression is that it can only learn linear decision boundaries. If two classes are arranged in concentric rings or an XOR pattern, no line will separate them, and logistic regression will plateau at high cross-entropy. The remedy is feature engineering: add polynomial or radial basis features, and logistic regression can carve non-linear boundaries in the original space—while remaining linear in the expanded feature space. This insight directly motivates the kernel trick.

$$P(y=1 \mid x) = \sigma(w_1 x_1 + w_2 x_2 + b) = \frac{1}{1+e^{-(w_1 x_1 + w_2 x_2 + b)}}$$

Section 03

Support Vector Machine

Support Vector Machines approach classification through the lens of structural risk minimization. Among all hyperplanes that correctly separate two classes, SVM selects the one with the largest margin—the distance between the hyperplane and the nearest training points of each class. This "maximum margin" criterion is not arbitrary: the VC dimension theory shows that classifiers with large margins generalize better, because they are less sensitive to small perturbations in the training data. The SVM is simultaneously a geometric construction and a principled statistical estimator.

The defining insight is that only a tiny subset of training points—the support vectors—actually determine the boundary. These are the points sitting exactly on the margin boundary, closest to the separating hyperplane. If you removed any non-support-vector point and retrained, the boundary would not change at all. This sparsity gives SVMs a kind of interpretive clarity: the model is fully described by a handful of critical examples. The soft-margin parameter C controls the tradeoff between maximizing the margin and tolerating misclassifications: small C allows wide margins at the cost of errors; large C pushes toward perfect training separation.

For non-linearly separable data, the kernel trick is one of the most elegant ideas in machine learning. The observation is: if we map inputs to a high-dimensional feature space $\phi(x)$, the data might become linearly separable there. But the SVM dual formulation only ever needs inner products $\phi(x_i)^T \phi(x_j)$, never the explicit feature vectors. A kernel function $K(x_i, x_j) = \phi(x_i) \cdot \phi(x_j)$ computes this inner product implicitly, often in $O(d)$ time even when the feature space is infinite-dimensional. The Gaussian RBF kernel $K(x, x') = \exp(-\|x - x'\|^2 / (2\sigma^2))$ corresponds to an infinite-dimensional feature space and can represent arbitrarily complex boundaries.

SVMs dominated applied machine learning through the 2000s because they were the first method offering both non-linear classification via kernels and theoretical generalization guarantees via margin maximization. Deep learning eventually supplanted them for most large-scale tasks—neural networks scale better with data and avoid the $O(n^2)$ kernel matrix cost—but SVMs remain unbeaten in many small-data, high-dimensional regimes. The kernel trick's conceptual DNA lives on in attention mechanisms and modern metric learning.

$$f(x) = \text{sign}\!\left(\sum_{i \in SV} \alpha_i y_i K(x_i, x) + b\right), \quad K_{\text{RBF}}(x, x') = \exp\!\left(-\frac{\|x - x'\|^2}{2\sigma^2}\right)$$
